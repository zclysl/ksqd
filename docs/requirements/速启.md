# 速启 · 软件快速启动器 —— 需求档

| 项 | 值 |
|---|---|
| 名称 | 速启（占位名，可改） |
| 平台 | Windows 10 / 11 |
| 技术栈 | Electron（已定；本机 Node v24.15.0 / npm 12.0.2 就绪） |
| 状态 | 已确认立项（2026-10-06） |
| 最后更新 | 2026-10-28（v1.6 分类排序与细节立项） |

## 一、模块目标

给 Windows 桌面用户一个「随叫随到」的软件启动面板：平时完全不占桌面空间，按下全局热键即刻唤出，按分类一眼找到目标软件，单击即启动。

- 面向谁：桌面图标多、找常用软件费劲的用户（自用为主）。
- 解决什么问题：桌面乱、找软件慢。

## 二、功能点

### F1 唤起与隐藏

- F1.1 全局热键（默认 `Alt+Space`，可自定义——见 F1.5）：面板未显示时唤出（屏幕居中、面板获得操作焦点）；已显示时按同一热键收起。
- F1.2 托盘图标：单击切换面板显示 / 隐藏；右键菜单至少含「退出」。
- F1.3 失焦自动隐藏：面板显示时，点击面板外任意位置（含切到其他应用）即自动隐藏；隐藏后不在任务栏留占位。
- F1.4 托盘常驻：应用启动后常驻系统托盘，不显示常驻主窗口。
- F1.5 自定义唤起快捷键：托盘右键菜单新增「快捷键设置…」，打开按键录制小窗（显示当前组合，按下新组合即录入）；默认组合 `Alt+Space`；组合须含修饰键（Ctrl / Alt / Shift / Win 之一）；新组合注册失败（被其他软件占用）→ 保留原快捷键并气球提示；设置持久化，重启应用后保留。
- F1.6 鼠标离开自动隐藏：面板显示中鼠标移出面板（不点击）约 300ms 后自动隐藏；移出后延迟内返回则不隐藏；与 F1.3 失焦隐藏并存。抑制场景：唤出后鼠标从未进入面板；添加 / 编辑浮层或面板内菜单打开中；条目拖动排序中；原生文件对话框打开中。

### F2 面板与分类

- F2.1 面板形态：居中弹出的紧凑面板；无边框；深色极简风格（简洁现代）。
- F2.2 分类视图：面板内软件按分类以标签页切换展示（图标 + 名称）；不设搜索框，分类即查找路径。
- F2.3 分类管理：可新建、重命名、删除分类；新建入口 = 标签栏末尾「＋」按钮（按钮文字仅「＋」，悬停提示「新建分类」）。
- F2.4 默认分类「未分类」（本档下文所称「未分类」均指该默认分类，改名后按当前名理解）：始终存在、不可删除；可改名（改名后界面各处按新名显示）；新添加软件默认归入。
- F2.5 删除分类时：该分类下软件自动移入「未分类」，条目不丢失。
- F2.6 悬停切换标签页：鼠标在分类标签上停留约 200ms 即自动切到该标签页；快速扫过多个标签不切换；条目拖动排序经过标签栏时不触发。
- F2.7 分类拖动排序：按住分类标签可拖动调整分类顺序（与条目拖动同一套指针机理：4px 阈值区分点击与拖动、原位占位、松手生效并持久化）；「未分类」恒在首位、不可拖动；拖动中悬停切标签不触发、鼠标离开隐藏不触发（与条目拖动同类抑制）；面板外松手 → 取消（顺序不变）。

### F3 软件管理

- F3.1 添加：「+」按钮打开系统文件选择器（限 .exe / .lnk），选中即添加；也支持将 .exe / .lnk 直接拖拽进面板添加。
- F3.2 添加时填写：名称（默认取文件名、可改）+ 分类（默认「未分类」）；图标默认取所选程序自带图标。
- F3.3 点击启动：单击软件图标即启动该程序，并同时收起面板。
- F3.4 编辑：可重命名、更换分类。
- F3.5 删除：从列表移除条目（仅移除记录，不卸载、不删除软件本体）。
- F3.6 重复添加：按目标路径判重，重复添加时提示「已存在」。
- F3.7 图标容错：平台默认接口取不到程序自带图标（返回系统通用图或失败）时，回退「直读提取」；仍取不到则维持现有表现。
- F3.8 拖动排序：按住条目拖动调整顺序，松手生效并持久化（重启应用后保持）；支持拖到其他分类标签上以移动条目到该分类（跨分类拖放移动）。
- F3.9 快捷方式自愈：添加的是 .lnk（快捷方式）时，同时记下它指向的真实程序位置；此后该快捷方式被删除 / 移动导致原路径失效，自动改用真实位置启动（用户无感）。真实位置同样失效时才按 F4.3 提示启动失败。
- F3.10 快捷方式图标自愈：条目为 .lnk 且其路径失效（文件不存在或无法解析到目标）时，图标改用该条目已登记的真实程序位置取图，取图链路与 F3.7 一致（平台图失灵则回退直读）；真实位置同样取不到时维持现有表现。条目记录的仍是用户添加时的路径，不因本条改写。
- F3.11 打开安装位置：条目右键菜单新增「打开安装位置」→ 打开资源管理器并选中目标——.exe 条目 = 其所在文件夹；.lnk 条目 = 已登记的真实程序位置所在文件夹（无登记值时用添加路径）；目标不存在 → 面板 toast 提示（不静默）。
- F3.12 删除确认的键盘确认：条目删除确认（F3.5）与分类删除确认（F2.3）打开时，按 Enter = 确认删除（一处确认只删一次，不得双触发）；Esc = 取消不变；鼠标点击「删除」照常生效；添加 / 编辑浮层的 Enter 不受本约束。

### F4 运行与数据

- F4.1 单实例：应用重复启动时唤出已有实例，不产生第二个面板。
- F4.2 持久化：软件列表、分类、设置保存在本机用户数据目录；重启应用后保留。
- F4.3 启动失败提示：目标文件不存在或启动失败时，面板给出简短可见提示，不静默失败。
- F4.4 空状态引导：列表中无软件时，面板提示「点击 + 添加软件」。

### F5 安装包

- F5.1 打包：一条命令（`npm run build`，命令名由设计定）生成 Windows 安装包（.exe 安装器），可重复生成。
- F5.2 安装与使用：双击安装包完成安装（可选安装目录）；安装后可从开始菜单或桌面快捷方式启动，功能与开发运行一致（F1～F4）。
- F5.3 卸载：可从系统卸载；卸载后程序目录移除，用户数据（软件列表 / 分类）保留，重装后仍可用。

### F6 开机自启动

- F6.1 开机自启动：开启后，应用随系统启动并常驻托盘（登录后热键即刻可用）；作用对象为已安装版本。
- F6.2 开关：托盘右键菜单提供「开机自启动」勾选项；默认开启；状态持久化。

### F7 图标体系

- F7.1 托盘图标：托盘区图标在 Windows 浅色与深色两种托盘底色下均清晰可辨（不因底色切换丢失对比度）；形态自定。
- F7.2 应用图标：安装后的程序（exe 与开始菜单 / 桌面快捷方式）与安装器 / 卸载器使用本应用自带图标，不沿用 Electron 默认图标。
- F7.3 面板顶栏图标：面板顶栏标题处显示本应用图标（与 F7.2 同源的同一份图标，不另存副本）。

## 三、边界（v1 明确不做）

- 不做搜索框；不做开始菜单 / 注册表自动扫描收录（软件全部手动添加）。
- 不支持 UWP / 微软商店应用；不支持启动文件夹、网址、命令。
- 不做云同步、账号、插件系统；不做自定义图标上传（默认取自带图标）。
- 拖动排序：分类（标签）排序仅支持拖动（见 F2.7）；不做置顶；跨分类拖放移动已放开（见 F3.8）。
- 界面仅中文；仅支持 Windows 10 / 11。
- 不做代码签名（无证书，首次安装可能出现系统 SmartScreen 提示）。
- 不做托盘图标的运行时主题自适应（单版形态在两种托盘底色下均可辨 = F7.1 的设计要求）；不支持用户上传自定义图标（软件图标取程序自带图标，见 F3.2）。
- 快捷方式自愈只作用于启动与图标取图两条链路（F3.9 / F3.10）；不改写条目记录的原始路径，不做快捷方式的自动重建或丢失提示。

## 四、验收标准

桌面 UI 类为确定性手工步骤；逻辑类以开发期单元测试 + 文件检查为准。

- AC-1 启动：`npm start` 应用正常启动无报错；托盘出现图标；任务栏无窗口占位。（F1.4）
- AC-2 唤起：按 `Alt+Space`（默认组合）面板居中弹出；再按收起；托盘图标单击等效。（F1.1、F1.2）
- AC-3 失焦隐藏：面板显示时点击面板外任意处，面板立即隐藏。（F1.3）
- AC-4 添加并启动：点「+」选一个 .exe → 出现在所选分类下；单击该图标 → 程序启动、面板收起。（F3.1、F3.2、F3.3）
- AC-5 拖拽添加：把 .exe 拖入面板 → 添加成功。（F3.1）
- AC-6 编辑与持久化：重命名 / 改分类 / 删除软件即时生效；重启应用后保持。（F3.4、F3.5、F4.2）
- AC-7 分类操作：新建 / 重命名 / 删除分类生效；删除含软件的分类后，其软件出现在「未分类」；「未分类」不可删除、可改名。（F2.3、F2.4、F2.5）
- AC-8 失败提示：删除某条目的目标文件后单击其图标 → 面板出现失败提示。（F4.3）
- AC-9 数据文件：数据保存在用户数据目录（具体路径由设计定），为可读 JSON。（F4.2）
- AC-10 单实例：再次启动应用 → 不出现第二个面板，唤出已有实例。（F4.1）
- AC-11 单元测试：核心逻辑（分类增删改、软件增删改、数据读写）开发期单元测试 `node --test` 全绿（测试文件随批次档归档）。（F2、F3、F4.2）
- AC-12 打包产出：打包命令成功，产出安装包文件（.exe）。（F5.1）
- AC-13 安装使用：双击安装包完成安装；从快捷方式启动 → 托盘出现、`Alt+Space` 唤起、添加并启动一个软件正常（与 AC-2 / AC-4 等效）。（F5.2）
- AC-14 卸载：卸载完成后程序移除；用户数据保留，重装后原有软件列表仍可用。（F5.3）
- AC-15 开机自启：开启状态下重启系统（或注销重登）→ 应用自动启动、托盘常驻、`Alt+Space` 可用；托盘菜单关闭后重启系统不自动启动。（F6.1、F6.2）
- AC-16 图标容错：对系统接口失灵的程序（复现样本：DeepSeek Harness）显示其自带图标而非系统通用图；对已有正常图标与取不到图标的程序无回归。（F3.7）
- AC-17 快捷键自定义：托盘右键菜单「快捷键设置…」→ 录制窗显示当前组合（默认 `Alt+Space`）；录入 `Ctrl+Alt+Q` 后新组合唤出 / 收起面板、原组合失效；重启应用后新组合仍生效；录入无修饰键组合（如 `F5`）被拒绝；录入被其他软件占用的组合 → 保留原快捷键并气球提示。（F1.5）
- AC-18 鼠标离开隐藏：面板显示中鼠标移出面板且不点击 → 约 300ms 后自动隐藏；移出后延迟内移回 → 不隐藏；唤出后鼠标从未进入面板 → 不自动隐藏；添加 / 编辑浮层或面板内菜单打开中、条目拖动排序中、原生文件对话框打开中 → 移出不隐藏。（F1.6）
- AC-19 悬停切标签：鼠标在非活动分类标签上停留约 200ms → 自动切到该标签页，内容区同步切换；快速扫过多个标签 → 不切换；条目拖动排序经过标签栏 → 不切换。（F2.6）
- AC-20 拖动排序：按住条目拖至同分类内新位置松手 → 顺序即时生效，重启应用后保持；拖到其他分类标签上松手 → 条目移入该分类（追加到末尾）；拖动中移出面板不自动隐藏、经过标签栏不切标签；在面板外松手 → 取消排序（顺序与分类均不变）。（F3.8）
- AC-21 图标体系：托盘图标在系统浅色 / 深色托盘底色下均可辨识（对比度不丢失）；安装后的程序（exe 与开始菜单 / 桌面快捷方式）、安装器与卸载器均显示本应用自带图标（非 Electron 默认图标）。（F7.1、F7.2）
- AC-22 快捷方式自愈：添加一个 .lnk 条目并成功启动 → 删除该 .lnk 文件 → 再次单击该条目 → 程序正常启动（不报「目标文件不存在」）；.lnk 与其指向的真实程序均不存在时才报启动失败。（F3.9 / F4.3）
- AC-23 面板顶栏图标：面板顶栏标题处显示本应用图标（与 F7.2 同源的同一份图标，形态与托盘一致）；开发运行与安装运行均显示。（F7.3）
- AC-24 快捷方式图标自愈：添加一个 .lnk 条目（图标显示其真实程序的自带图标）→ 删除该 .lnk 文件 → 再次取该条目图标 → 仍显示真实程序的自带图标，而非系统通用快捷图；该 .lnk 与其指向的真实程序均不存在、或真实程序取不到图标时，维持既有表现（系统通用图或首字符占位块）；对仍在盘上且可解析的 .lnk 条目与 .exe 条目，取图结果与本条落地前一致（无回归）。（F3.10）
- AC-25 分类拖动排序：按住分类标签拖至新位置松手 → 顺序即时生效、重启保持；「未分类」不可拖且恒首位；拖动经过标签栏不触发悬停切换；面板外松手 → 取消；拖动中移出面板不自动隐藏。（F2.7）
- AC-26 打开安装位置：.exe 条目右键「打开安装位置」→ 资源管理器打开所在文件夹并选中文件；.lnk 条目（原快捷方式已删除）→ 打开真实程序所在文件夹；目标均已不存在 → toast 提示。（F3.11）
- AC-27 删除确认 Enter 确认：条目删除确认 / 分类删除确认中按 Enter → 删除生效且只删一次（条目不重复移除 / 分类不重复请求）；Esc → 取消；鼠标点「删除」照常生效。（F3.12）
- AC-28 新建分类按钮：标签栏末尾按钮仅显示「＋」（无「新建分类」文字）；悬停显示 title「新建分类」；点击行为与现状一致。（F2.3）

## 五、依赖

- 上游：Node 24 + npm（已就绪）；Electron 与打包工具经 npm 安装（版本与选型见设计档；安装包为本机生成）。
- 运行环境：Windows 10 / 11；运行时不依赖网络。
- 下游：无（本机自用，无外部系统对接）。
