# 速启（SuQi）

Windows 桌面软件快速启动器。一个常驻系统托盘的小程序：按一个全局热键唤出面板，点图标就打开软件，不用再去桌面或开始菜单里翻。

- 当前版本：1.5.0
- 适用系统：Windows 10 / 11
- 技术形态：Electron 桌面应用，界面为中文

## 功能

### 唤出与收起

- `Alt+Space` 全局热键唤出／收起面板，在哪个窗口里都有效。
- 热键可自定义：托盘右键 →「快捷键设置…」，在弹出的小窗里直接按下新组合即可，设置会保存下来。
- 新组合必须带修饰键（`Ctrl` / `Alt` / `Shift` / `Win` 之一），否则不予采用。
- 新组合如果被别的软件占用，会保留原来的热键并弹出气泡提示，不会变成「按了没反应」。
- 单击托盘图标也能切换面板显示／隐藏。
- 面板失焦自动隐藏；鼠标移出面板约 300 毫秒后自动隐藏（正在拖动排序、打开菜单或浮层时不隐藏）。

### 面板与分类

- 面板为 720×480 的深色无边框卡片，屏幕居中弹出。
- 顶部是分类标签页，点标签切换分类；鼠标悬停约 200 毫秒也会自动切换。
- 分类可以新建、重命名、删除。
- 自带的「未分类」不可删除（可以改名）；删除某个分类时，它下面的软件会自动移入「未分类」，不会跟着一起被删掉。
- 面板里没有搜索框 —— 这个版本不做搜索。

### 软件管理

- 添加：点面板里的「+」选择 `.exe` 或 `.lnk` 文件，也可以把文件直接拖进面板。
- 名称默认取文件名，可随时改；图标取文件自带图标，取不到时回退到直接读取，再不行用占位图标。
- 启动：单击图标即启动软件，面板同时收起。
- 编辑：右键条目可重命名、改分类；删除只移除速启里的这条记录，不删你硬盘上的软件。
- 按路径判重，同一个软件不会重复添加。
- 拖动排序：条目可在分类内拖动排序，也能拖到其他分类标签上跨分类移动。
- 快捷方式自愈：添加 `.lnk` 时会记下它的真实目标位置。以后原快捷方式被删掉或失效，启动和取图标仍走真实位置，条目本身不用重新添加。

### 数据与稳定性

- 单实例运行，重复启动只会唤出已有的那个。
- 数据存本机，不联网、不同步。
- 启动软件失败时给出可见提示，不静默失败。
- 列表为空时显示引导，告诉你怎么添加第一个软件。

### 开机自启动

- 托盘右键菜单里有「开机自启动」，默认开启，选择会被记住。
- 仅安装版（NSIS 安装器装出来的）支持这一项；直接跑源码时菜单项会标注「仅安装版可用」。

### 图标

- 托盘图标在浅色和深色任务栏底色下都可辨认。
- 应用窗口、安装器、卸载器都使用自带的 `build/icon.ico`，不是 Electron 默认图标。

## 安装

两种用法：

1. **用安装包（推荐）**：下载 `Suqi-Setup-1.5.0.exe`，双击安装。安装时可选择安装目录，会自动创建开始菜单项和桌面快捷方式。卸载时保留你的软件列表数据。
2. **从源码运行**：见下面的「开发」一节。

安装包没有做代码签名，Windows SmartScreen 可能会弹出「未知发布者」提示，确认后继续安装即可。

## 使用说明

1. 装好后程序常驻系统托盘（任务栏右侧），不占任务栏窗口位。
2. 按 `Alt+Space` 唤出面板；再按一次收起。托盘单击同样可以。
3. 点面板里的「+」选一个 `.exe` 或 `.lnk`，或把桌面上的快捷方式直接拖进面板，就添加好了。
4. 单击图标启动软件，面板自动收起。
5. 软件多了就在顶部建分类；右键标签可重命名或删除分类，拖动条目可排序或换分类。
6. 右键条目可重命名、改分类、删除记录。
7. 托盘右键菜单：
   - 显示面板
   - 开机自启动（勾选状态）
   - 快捷键设置…
   - 退出

### 数据文件

数据保存在 `%APPDATA%\速启\data.json`，是普通 JSON 文本文件，可以直接查看和备份。保存时先写临时文件再改名替换，避免写一半断电导致文件损坏。卸载软件不会删除这个文件，重装后列表还在。

## 暂不支持

- 面板内搜索（本版本没有搜索框）
- 自动扫描已安装软件（需要手动添加）
- UWP / Microsoft Store 应用
- 云同步、多设备共享
- 自定义图标上传
- 分类排序

## 开发

```bash
npm install       # 安装依赖
npm start         # 直接运行（Electron）
npm run dist      # 打包 Windows NSIS 安装器，产物在 dist/
npm run test:unit # 跑单元测试（测试文件不进库，克隆后无此命令的脚本）
```

目录结构：

- `src/main/` —— 主进程：窗口、托盘、热键、数据、图标、启动、开机自启动
- `src/renderer/` —— 面板界面
- `src/preload/` —— 渲染进程与主进程之间的桥接
- `build/` —— 打包资源（图标、安装脚本）
- `docs/` —— 需求档、设计档；开发过程档案（`docs/batches/`，含单元测试）只留本机，不进库
